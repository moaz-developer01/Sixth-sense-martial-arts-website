# Launch Checklist

## Content

- [ ] Replace all placeholder facts and email addresses.
- [ ] Add real academy photography with descriptive alt text.
- [ ] Proofread titles, headings, calls to action, and contact details.
- [ ] Confirm every testimonial and credential with permission.

## Technical

- [ ] Set the production domain in canonical tags, Open Graph tags, `robots.txt`, and `sitemap.xml`.
- [ ] Validate JSON-LD with Google's Rich Results Test.
- [ ] Test mobile layout, keyboard navigation, focus states, and reduced motion.
- [ ] Check Core Web Vitals and broken links.
- [ ] Submit the sitemap in Google Search Console and Bing Webmaster Tools.
