# Sixth Sense Martial Arts

Static, mobile-first homepage rebuild for Sixth Sense Martial Arts in Coppell, Texas.

## Preview

With PHP installed, run:

```powershell
php -S localhost:8000 router.php
```

Then open <http://localhost:8000>.

## Structure

- `dist/`: deployable HTML, CSS, JavaScript, and image references only.
- `project-docs/`: build notes, content planning, and SEO/AEO/FEO requirements.
- `router.php`: local PHP preview router.

Replace the documented placeholder imagery and verify all business facts before launch.
